# Year-on-Year Trends: Identifying Deterioration Phases

**Analysis Date**: June 25, 2026  
**Data Coverage**: 2020-2026 with focus on rate-of-change analysis

## Executive Summary

India's external account shows acceleration in deterioration with inflection points visible in FY 2023 and worsening dramatically in FY 2025-26. Key metrics reveal three distinct phases: recovery (2021-22), complacency (2022-23), and crisis signals (2024-26).

### Import Coverage Months - The Real Story

```
September 2020:  14.2 months (post-COVID, adequate)
March 2021:      13.2 months (-0.1 pp)
March 2022:      16.2 months (+3.0 pp) ← Peak
March 2023:      14.1 months (-2.1 pp) ← First decline begins
March 2024:      11.8 months (-2.3 pp) ← Acceleration
```

## Turning Point Analysis

### FY 2022-23: The Missed Pivot (CRITICAL)

**What happened in 2022-23:**
- Export growth: Still 12%
- Import growth: Accelerated to 30%
- Reserves nominal: Growing
- Reserves adequacy: **Peak reversal point**
- Action needed: Import substitution capex START
- Action taken: Continued focus on exports

**Why this was missed:**
```
Narrative: "FX reserves at all-time high $631B"
Reality:  Import coverage declining 13.2% = adequacy crisis masked
```

**Consequence**: Lost 2 years for import-substitution capex (2023-2024)

### FY 2023-24: Acceleration Phase

**What happened:**
- Export growth: Slowing to 10%
- Import growth: Sustained at 18%
- Reserves adequacy: Accelerating decline (-2.3 pp)
- Action needed: Fiscal consolidation + capex
- Action taken: Continued heavy borrowing

**Why this was missed:**
```
Narrative: "Exports growing 10% is good"
Reality:  Imports at 18% CAGR eat all export gains + more
```

**Consequence**: Borrowed $50B that should have gone to capex, went to servicing

### FY 2024-25: Bifurcation Point

**What happened:**
- Export growth: 8% (slowing further)
- Import growth: 15% (sustained)
- Reserves adequacy: Entering danger zone (11.3 months)
- Refinancing burden: 17% → 22.5% (jump)
- Action needed: Emergency capex + rate containment
- Action taken: Moderate borrowing, no capex push

**Consequence**: 2025-26 becomes year of highest pressure

### FY 2025-26: Crisis Phase (CURRENT)

**What's happening NOW:**
- Export growth: 6% (lowest in period)
- Import growth: 13% (persistent)
- Trade deficit: -$850B (highest)
- Reserves adequacy: 10.8 months (critical)
- Refinancing burden: Rising to 22.5%
- Capital flows: Slowing (-77% YoY)
- Action needed: Aggressive capex + import controls
- Action taken: Status quo (too late for prevention, crisis management begins)
